# ZiniQuest
**ZiniQuest** is a subject-agnostic, gamified mobile learning platform designed to transform the academic experience for tertiary students. By integrating game mechanics into traditional study material, the app aims to increase engagement through achievement-based learning.
## 🚀 Overview
The platform allows students to earn XP, collect badges, and climb course-specific leaderboards as they progress through academic content. It is designed to be flexible enough to host any field of study, providing a standardized gamification layer for diverse educational departments.
## ✨ Key Features
 * **Gamified Progression:** Earn XP and unlock badges for completing lessons and quizzes.
 * **Live Leaderboards:** Real-time ranking systems for healthy academic competition.
 * **Role-Based Access:** Dedicated interfaces for Students, Instructors, and Administrators.
 * **Resilient Connectivity:** Built-in "No Internet" handling to ensure a smooth user experience during demonstrations and low-bandwidth situations.
## 🛠 Tech Stack
 * **Framework:** React Native & Expo
 * **UI Library:** React Native Paper (Material Design 3)
 * **Backend:** Firebase (Authentication, Firestore, and Cloud Functions)
 * **Storage:** Cloudinary
